# Iron Pulse Gym — Backend API

## Quick Start

```bash
npm install
npm start        # production
npm run dev      # development (auto-reload, Node 18+)
```

Server runs on **http://localhost:4000**

Default admin: `admin@ironpulse.com` / `admin123`

---

## API Reference

### Auth
| Method | Route | Auth | Description |
|--------|-------|------|-------------|
| POST | `/api/auth/login` | ❌ | Login → JWT token |
| GET  | `/api/auth/me`    | ✅ | Get current admin |
| POST | `/api/auth/change-password` | ✅ | Change password |

## Authentication

All protected routes require:
```
Authorization: Bearer <token>
```

Token is returned by `POST /api/auth/login`.

---

## Production Upgrade Path

1. Replace in-memory `DB` with PostgreSQL / MongoDB
2. Use `bcryptjs` for password hashing instead of SHA-256
3. Set `JWT_SECRET` as environment variable
4. Add rate limiting (`express-rate-limit`)
5. Add HTTPS (reverse proxy: Nginx / Caddy)
6. Hook notification routes to Twilio / WhatsApp Business API
